# 场景一 · 带引用的文档问答 Agent

主线项目，D5–D11 的技术骨架。

## 要解决的问题

用一句话写给完全不懂技术的人：

> 我的资料散在几十份 PDF 和 Word 里，想问一句话就得翻半天；而且我不敢相信聊天机器人随口给的答案。

## 交付标准

- [ ] 能上传文档入库
- [ ] 回答必须带 `[文件名 p.页码]` 引用
- [ ] 资料里没有依据时明确回答"资料中未提及"，不编造
- [ ] 上下文超长时按相关性裁剪，而不是直接截断
- [ ] 检索工具化，可被 Agent 循环调用
- [ ] 有 50 条评测集和一条命令出报告的评测脚本

## 技术链路

```
文档 → 加载清洗 → 切分 → Embedding → Chroma(带 metadata)
                                              │
用户提问 → Embedding ──┬── 向量 top-20 ──┐
                       └── BM25 关键词 ──┴→ Rerank top-5 → Prompt(要求引用) → 回答
                                                              │
                                                    工具化 → Agent 循环
```

## 关键指标（D7 定义口径，D11 自动统计）

| 指标 | 定义 | 目标 |
|---|---|---|
| 召回率 | top-5 命中标准答案所在 chunk 的比例 | 待填 |
| faithfulness | 回答中的断言有多少能在依据里找到 | 待填 |
| 幻觉率 | 无依据问题里编造答案的比例 | ≤ 20% |
| 平均延迟 | 从提问到完整回答 | 待记录 |
| 单次成本 | 按 token 计价 | 待记录 |
