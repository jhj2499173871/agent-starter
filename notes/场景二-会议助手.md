# 场景二 · 会议智能助手

亮点项目，D13 集中攻坚，复用场景一的检索与工具化能力。

## 要解决的问题

> 开完会记不住谁答应了什么、什么时候交；想找上次讨论过的内容只能翻聊天记录。

## 交付标准

- [ ] 一段真实录音/视频能跑通：转写 → 摘要 → 决议 → 待办
- [ ] 待办带负责人与截止时间，且能看出是从哪句话推断的
- [ ] 转写文本写入场景一的向量库，实现"上次谁提过 X"的跨会议检索
- [ ] 待办抽取准确率有数字、有错误分类

## 技术链路

```
录音/视频 ──→ MiMo 音频理解 / ASR ──→ 转写文本
                                        │
                          ┌─────────────┼──────────────┐
                          ↓             ↓              ↓
                    摘要生成      待办抽取(pydantic)   写入场景一向量库
                                  {title, owner,          (metadata: 会议名+日期+参会人)
                                   deadline, priority}         │
                                                               ↓
                                                  跨会议检索："上次谁提过 X"
```

## 与场景一的关系（面试必答）

会议转写文本**就是场景一知识库里的一类文档**，只是 metadata 多了"会议名称、日期、参会人"。
"上次谁提过这个方案" = 一次带 metadata 过滤的向量检索，**不需要第二套代码**。
如果你写了两套，说明抽象没做好。

## 关键指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 待办抽取准确率 | 抽出的待办与人工标注的匹配率 | 待填 |
| 摘要事实错误率 | 摘要里与原文不符的断言比例 | 待填 |
| 跨会议检索命中率 | 10 个"上次谁提过 X"问题的命中数 | 待填 |
